# Evidencias versionadas

Registrar aquí resultados pequeños, revisados y compartibles por ID de corrida, junto con manifiestos de artefactos externos. No subir automáticamente JSON locales sin revisión. El fichero local `feasibility-local.json` es transitorio; después de verificar privacidad, procedencia y derechos, incorporar una copia identificada y su hash. Ver [metodología](../docs/research-methodology.md).

Los reportes de corpus enlazan corrida, fuente y snapshot/manifiesto. Conservar solo evidencia revisada y legalmente compartible; los archivos de trabajo y originales autorizados viven fuera de Git en el espacio de laboratorio. No usar métricas descriptivas como estimaciones de una población sin diseño apropiado.
